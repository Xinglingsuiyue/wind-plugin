# wind-plugin

#### 介绍

1.  各大平台热搜榜单
此功能使用了一些免费的api获取各平台热搜信息，哔哩哔哩、抖音、微博、今日头条、知乎、百度等平台的热搜榜单

2.  其他
暂时只有菜谱查询的功能，可以教你如何做菜

3.  轻量修仙
此功能适合大部分群聊使用，不会像其他修仙插件那样玩法过多容易刷屏，仅仅只有修炼突破等功能。

4.  更多功能仍在咕咕咕,新手写的插件，bug可能有点多，更新比较频繁


#### 安装教程

```
git clone https://gitee.com/wind-trace-typ/wind-plugin.git ./plugins/wind-plugin
```


#### 使用说明

| 指令  | 功能描述  |
|---|---|
| wind帮助  | 获取帮助菜单  |
| bilibili周榜/哔哩哔哩周榜  | 获取哔哩哔哩周榜信息和链接，后跟数字也可自定义期数  |
| bilibili热搜/bilibili热搜榜/哔哩哔哩热搜  | 获取bilibili热搜榜单  |
| 抖音热搜/抖音热搜榜/tiktok热搜  | 获取抖音热搜榜单  |
| 微博热搜/微博热搜榜 | 获取微博热搜榜单  |
| 知乎热搜/知乎热搜榜 | 获取知乎热搜榜单  |
| 今日头条热搜/今日头条热搜榜 | 获取今日头条热搜榜单  |
| 今日头条新闻/今日头条热点新闻 | 获取今日头条热点新闻  |
| 做菜+菜名/做菜+菜名+数量  | 获取菜的做法，以聊天记录形式发出，不带数量默认返回5个菜的做法，最高只能查10个菜的做法  |
| 修仙/修炼  | 修炼增加自身灵力  |
| 突破  | 突破自身境界  |
| 服用丹药  | 使用丹药获取灵力  |
| 查看境界  | 查看自身境界  |
| 排行榜  | 修仙境界排行榜  |
| 决斗@群友/pk@群友  | 和群友pk  |
| 修仙境界列表  | 修仙境界列表  |
